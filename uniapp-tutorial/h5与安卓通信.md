# h5与安卓通信

## H5 和 Android WebView 通信核心分双向：
1. Android 原生 → H5：原生直接调用 JS 代码
2. H5 → Android 原生：H5 调用 Android 提供的原生方法

## 一、前置准备（Android 端必须配置）
### 1. 开启 WebView 支持 JS
```
WebSettings webSettings = webView.getSettings();
webSettings.setJavaScriptEnabled(true); // 必须开启
webSettings.setAllowFileAccess(true);
```

### 2. 开启跨域 / 安全配置（可选）
```
// 允许混合内容（http + https）
if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.LOLLIPOP) {
    webSettings.setMixedContentMode(WebSettings.MIXED_CONTENT_ALWAYS_ALLOW);
}
```

## 二、方案 1：H5 调用 Android 原生（最常用）
### 核心原理
Android 给 WebView 注入一个JS 对象，H5 直接调用这个对象的方法。
### 1. Android 端：创建 JS 接口类
```
public class JsBridge {
    private Context mContext;

    public JsBridge(Context context) {
        mContext = context;
    }

    // H5 可以调用的方法，必须加 @JavascriptInterface 注解！
    @JavascriptInterface
    public void showToast(String msg) {
        Toast.makeText(mContext, msg, Toast.LENGTH_SHORT).show();
    }

    @JavascriptInterface
    public String getDeviceInfo() {
        // 返回设备信息给 H5
        return "Android 设备，版本：" + Build.VERSION.RELEASE;
    }
}
```
### 2. Android 端：注入到 WebView
```
// 第二个参数 "AndroidNative" 就是 H5 要调用的对象名！
webView.addJavascriptInterface(new JsBridge(this), "AndroidNative");
```

### 3. H5 端：调用 Android 方法
```
<script>
// 调用原生弹 Toast
function callAndroidToast() {
  // AndroidNative 必须和原生注入的名字一致
  AndroidNative.showToast("我是H5传给安卓的消息");
}

// 获取原生返回的数据
function getAndroidInfo() {
  let info = AndroidNative.getDeviceInfo();
  console.log("安卓设备信息：", info);
}
</script>

<button onclick="callAndroidToast()">调用安卓Toast</button>
<button onclick="getAndroidInfo()">获取安卓信息</button>
```
## 三、方案 2：Android 原生调用 H5 JS
### 核心原理
原生通过 webView.evaluateJavascript() 执行 H5 里的 JS 函数。
### 1. H5 端：定义供原生调用的 JS 方法
```
<script>
// 安卓可以直接调用这个方法
function setDataToH5(data) {
  document.getElementById("msg").innerText = data;
  return "H5 已收到：" + data;
}
</script>
<div id="msg"></div>
```

### 2. Android 端：调用 JS 方法
```
// Android 4.4+ 推荐使用（异步，支持回调）
webView.evaluateJavascript("setDataToH5('我是安卓传给H5的数据')", new ValueCallback<String>() {
    @Override
    public void onReceiveValue(String value) {
        // value 是 JS 方法的返回值
        Log.d("WebView", "H5 返回：" + value);
    }
});
```
## 四、方案 3：URL Schema 通信（兼容老版本 / 无注入场景）
### 原理
H5 跳一个自定义协议链接（如 myapp://action?param=123），Android 拦截 URL 解析参数。
